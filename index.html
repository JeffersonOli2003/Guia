Comandos Essenciais

git init

O comando "git init" inicializa um novo repositório Git no diretório atual, preparando o projeto para começara ser versionado.

git add .

O "git add ." adiciona todas as alterações do projeto à área de preparação do Git, deixando-as prontas para o commit.

git commit -m "mensagem de commit"

O comando commit ele coloca uma mensagem que voce vai escrevar para que voce saiba o que voce fez naquele commit, O git commit -m "mensagem" salva as alterações preparadas no histórico do Git, identificando-as com uma mensagem descritiva.

git push -u origin main

O "git push -u origin main" envia os commits do seu projeto para o repositório remoto, como o GitHub, na branch main.

DICA: Primeiro, o git init para iniciar o repositório; depois, o git add . para preparar todas as alterações; e, por fim, o git commit -m "mensagem" para salvar essas alterações no histórico.
FICA A DICA:Lembre-se da ordem: git init inicia, git add . prepara e git commit salva as alterações.
