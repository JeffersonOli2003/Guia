Comandos Essenciais

GIT INIT

O comando "git init" inicializa um novo repositório Git no diretório atual, preparando o projeto para começara ser versionado.

GIT ADD .

O "git add ." adiciona todas as alterações do projeto à área de preparação do Git, deixando-as prontas para o commit. Ele é o primeiro!

GIT COMMIT -M [MENSAGEM]"

O comando commit ele coloca uma mensagem que voce vai escrevar para que voce saiba o que voce fez naquele commit, O git commit -m "mensagem" salva as alterações preparadas no histórico do Git, identificando-as com uma mensagem descritiva.

GIT PUSH -U ORIGIN MAIN

O "git push -u origin main" envia os commits do seu projeto para o repositório remoto, como o GitHub, na branch main.

GIT STATUS

O "git status" mostra o estado atual do projeto, indicando quais arquivos foram modificados, adicionados ou ainda não estão sendo acompanhados pelo Git.

GIT FETCH

O "git fetch" verifica se o repositorios remoto tem modificações em relação ao local.

GIT CLONE [link do repositorio]

O "git clone" copia um repositório remoto para o computador, permitindo trabalhar com o projeto localmente.

GIT PULL

O "git pull" baixa as alterações mais recentes do repositório remoto e atualiza o projeto local.

GIT BRANCH

O comando "git branch" Mostra as branches existentes no repositório. É essencial para saber em qual branch você está trabalhando e visualizar as outras branches.

GIT SWITCH

O comando "git switch nome-da-branch"Permite trocar de uma branch para outra. É muito usado quando você precisa trabalhar em diferentes funcionalidades ou versões do projeto.

GIT MERGE

O comando "git merge nome-da-branch" Junta as alterações de uma branch em outra. É muito importante para integrar o trabalho feito em diferentes branches.

GIT LOG

Mostra o histórico de commits do projeto, permitindo visualizar o que foi alterado, quem fez a alteração e as mensagens dos commits.

MINI RESUMO DOS COMANDOS GIT

1. GIT INIT — Cria/inicializa o repositório Git.
2. GIT STATUS — Verifica o estado atual dos arquivos.
3. GIT ADD . — Adiciona as alterações para serem preparadas para o commit.
4. GIT COMMIT -M "[MENSAGEM]" — Salva as alterações no histórico do Git.
5. GIT BRANCH — Visualiza as branches disponíveis.
6. GIT SWITCH — Troca para outra branch.
7. GIT MERGE — Junta as alterações de uma branch em outra.
8. GIT LOG — Consulta o histórico de commits.
9. GIT FETCH — Verifica alterações disponíveis no repositório remoto sem aplicá-las ao projeto local.
10. GIT PULL — Baixa e integra as alterações do repositório remoto.
11. GIT PUSH -U ORIGIN MAIN — Envia os commits locais para o repositório remoto.
12. GIT CLONE [link do repositório] — Copia um repositório remoto para o computador.
